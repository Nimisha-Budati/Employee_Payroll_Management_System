How it works

  1. Set the office’s latitude and longitude.
  2. Choose an allowed radius around that point.
  3. Employees grant GPS permission before check-in or check-out.
  4. The server verifies their distance and allows one of each action per day.

For reliable GPS, use HTTPS or localhost and enable device location services.
